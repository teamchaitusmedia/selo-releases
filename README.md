# Selo releases

**Install Selo:** download **[Selo-Setup.exe](https://github.com/teamchaitusmedia/selo-releases/releases/latest/download/Selo-Setup.exe)** and run it. Everything is inside it, all the AI models included; nothing else to download or install. That link always gives the newest version.

Windows may say "Windows protected your PC": click **More info**, then **Run anyway**.

After that, Selo updates itself from here (the small `Selo_<version>_x64-setup.exe` in each release is that update; you never need it by hand).
